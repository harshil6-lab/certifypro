# CertifyPro Frontend

Frontend for **CertifyPro – Certificate Automation & Verification System**.  
Built with React + Vite + Tailwind for a clean admin UI.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS / shadcn-ui

## Run Locally

```bash
cp .env.example .env
npm install
npm run dev
```

## Environment Setup

Create `frontend/.env` (you can start from `frontend/.env.example`) and set:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
- `VITE_ADOBE_CLIENT_ID` — Get this from Adobe Developer Console > Your Project > Credentials. See `https://developer.adobe.com/console`.
